How to set this up
  1. On GitHub, make a new private repository (for example notebook). Any name works.
  2. Make a token at github.com/settings/personal-access-tokens: under Repository access choose Only select repositories and pick that repository (and your Log’s, if you’ll publish). Under Permissions, set Contents to Read and write. Choose an expiration as long as you like.
  3. Type the repository as you/notebook, paste the token, and tap Connect.

The token is kept on this device only. Entries are saved as Markdown files, each with its photos in an images folder beside it, so they’re yours to read on GitHub or anywhere else.

Photos & Videos

Photo Size

Optimized photos are resized to 2,400 pixels on the long side, about half a megabyte each, and leave out location data. Videos are kept as they are, up to 50 MB each. GitHub suggests keeping a repository under 1 GB.

Publish to Log

Adds “Publish to Log” to each entry’s ••• menu, which copies the entry and its photos into entries/ of this repository, where a site like the Log picks it up. Leave it blank to turn it off. The token needs access to this repository too.
